# Incident Severity Matrix

| Severity | Definition | Response Time | Example |
|----------|------------|---------------|---------|
| **SEV-1** | Complete outage or major data loss | Immediate (page) | All users cannot login, payment system down |
| **SEV-2** | Significant degradation | < 15 min | High error rate on critical path, major feature broken |
| **SEV-3** | Minor impact or workaround available | < 1 hour | Non-critical feature broken, elevated latency |
| **SEV-4** | Cosmetic / low impact | Next business day | UI bug, documentation issue |

## Escalation Path
1. On-call primary
2. On-call secondary / team lead
3. Engineering manager
4. VP / CTO (for SEV-1)
